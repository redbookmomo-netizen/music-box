# 圣咏玫瑰 · 皇家巴洛克机械八音盒

专为手机竖屏（含 **iPhone 18 Pro Max** 灵动岛安全区、`100dvh` 满屏与 `120Hz ProMotion` 高刷）及桌面浏览器打造的交互式古董机械八音盒玩具。

在线访问地址（GitHub Pages）：
<https://redbookmomo-netizen.github.io/music-box/>

## 核心亮点

- **原画级无缝哥特全景与三维旋转结构**：100% 保留螺钿贝母、深红丝绒盒盖、珍珠红宝石镶嵌与描金玫瑰浮雕原画质感，向上延展哥特彩绘玫瑰花窗石拱穹顶，向下衔接雕花鎏金木桌。
- **盒内三重机械联动**：
  - **三层立体巴洛克转台**：顶部皇家十字珍珠红宝石皇冠、中层双色雕塑鎏金玫瑰花环、底层描金粉玫红宝石瓷鼓随音乐立体旋转，并浮现丝绸流光残影。
  - **盒盖椭圆宝镜同步倒影**：深红丝绒盒盖内的椭圆镜面实时映出反向旋转的皇冠倒影与彩绘花窗微光。
  - **黄铜音筒与 28 齿银色音梳**：110 颗黄铜音钉沿滚筒立体翻滚，每一个音符实时拨动对应音高的银色钢片齿高频震颤并绽放四芒星尘。
- **彩绘花窗丁达尔圣光与三层景深微尘**：多束斜射体积圣光随呼吸轻柔摇曳，175 颗远中近景金粉微尘穿行光柱时自然点亮，螺钿贝母流淌虹彩珠光，右侧古堡双烛微光摇曳。
- **瑞士古董钢片音梳物理声学合成**：Web Audio 实时合成悬臂钢片非谐波泛音列 + 4ms 黄铜拨针金属瞬态 + 玫瑰木螺钿盒体三段共鸣 + 哥特石拱教堂阻尼混响，支持 iOS 静音键模式下正常外放。
- **指尖亲手把玩**：不仅可点击上发条自动奏鸣，还可直接用手指在皇冠玫瑰上左右滑动亲手转响八音盒，支持一键切换「哥特全景 / 机芯特写 / 原画横幅」与双击纯净沉浸模式。
